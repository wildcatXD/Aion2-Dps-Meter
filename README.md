# 빛 레기온 미터기

아이온2 전투분석을 위한 **빛 레기온 전용** 미터기입니다. 업스트림 [AION2Meter4J](https://github.com/TK-open-public/Aion2-Dps-Meter) (MIT, Copyright 2026 TK-open-public)를 포크했습니다.

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

- Spoqa Han Sans Neo, Freesentation, Pretendard (OFL 1.1)
- NEXON Lv2 Gothic, Tmoney Round Wind (Custom License)

업스트림 공개 프로젝트는 2026-06-19 기준으로 종료되었습니다. 이 포크는 빛 레기온 내부용으로 파서·배포 채널을 유지합니다. 운영측 요청, 패킷 암호화, 공식 사용중단이 있으면 여기서도 멈춥니다.

길드 웹의 공지·일정 참여·아그로는 오버레이 헤더 종 아이콘으로 동기화합니다. 웹 `/meter-link`에서 코드를 만들고 미터기 설정에 넣으면 됩니다. 전투기록 업로드 API는 아직 없습니다. 유지 절차는 [MAINTAINING.md](MAINTAINING.md)를 봅니다.

## 지금 되는 것 / 아직 안 되는 것

**지금 됩니다**

- Windows 오버레이 DPS (Npcap, 관리자 실행, 캐릭터 선택창에서 시작)
- 파티 기여도 / 보스 체력 기여도, 보스 HP 바, 스킬·버프 상세
- 전투 기록 20개 (RAM), 파티 신청 패널, 컴팩트/클릭 통과/자동 숨김/단축키
- 빛 레기온 테마 (네이비 `#0b0d17` + 앰버 `#fbbf24`). 업스트림 초록/금색 기본값은 한 번 레기온 테마로 바꿉니다. 직접 고친 색은 유지합니다.
- **실험적 nDPS**: 설정 → 딜 지표에서 `개인 nDPS (실험)`을 고르면 파티 시너지를 근사 제거한 값을 바·숫자에 씁니다. 상세 패널에는 rDPS와 nDPS를 같이 보여 줍니다.
- **길드 웹 연동 (알림·참여)**: 웹 `/meter-link` 코드를 미터기 설정에 넣으면, 헤더 종 아이콘으로 안 읽은 공지·내 일정·열린 일정 참가·아그로 참가/불참을 받을 수 있습니다. 30초마다 갱신합니다.
- 오버레이 창을 **주 모니터** 해상도 전체 범위에서 자유롭게 움직일 수 있습니다 (1.8.5+). 1920x1080보다 큰 주 모니터에서 화면 오른쪽/아래로 못 옮겨지던 문제를 고쳤습니다. 다른 모니터로 넘기는 것은 아직 없습니다 (아래 [다음 업데이트 계획](#다음-업데이트-계획)).
- 켜 둔 동안 30분마다 새 버전을 다시 확인합니다 (1.8.7+). 작업표시줄 숨겨진 아이콘(트레이)에 미터기가 등록됩니다 (1.8.8+).
- 업데이트 다운로드가 끝나면 설치 마법사 없이 종료 → 무인 설치 → 재시작까지 진행합니다 (1.8.10+). 그 이전 버전에서 1.8.10을 받을 때는 설치 주체가 예전 코드라 Setup 창이 한 번 더 뜰 수 있습니다.
- 본인·파티 닉네임 패킷의 extraFlag를 건너뛰어, 딜이 숫자 ID로만 보이던 문제를 고쳤습니다 (1.8.10+). 스폰을 못 받은 허수아비 등은 `미확인 대상`으로 표시합니다. 캐릭터 선택 전에 미터기를 못 켠 경우에는 전투 uid로 이름을 보조 탐지하고, 솔로면 `나`로 표시합니다 (1.8.11+).

**아직 없습니다**

- 길드 웹 업로드 API / 히스토리 업로드 버튼
- 권성 직업 카탈로그
- 권성 직업 아이콘·스킬 카탈로그 (1.7.5 json에 19xxxxxx 없음)

- 보스 스폰 알림, 오드에너지 등 리소스 게이지 표시, 다른 모니터로 오버레이 이동 (아래 [다음 업데이트 계획](#다음-업데이트-계획) 참고)

## nDPS (실험)

아이온2에서 말하는 nDPS는 전투시간을 정규화한 값이 아니라, **남이 걸어 준 파티 시너지를 뺀 개인 딜**입니다. 낫터기 공식은 타격마다 `기존 PvE 증폭 + 버프 증폭`을 합친 뒤 차이만 시너지로 뺍니다. 이 미터기는 장비 스탯 시트를 못 읽어서 개인 증폭을 0으로 두고, 알려진 파티 버프만 보수적으로 뺍니다.

| 버프 | 시너지 근사 | 비고 |
| --- | --- | --- |
| 호법 질풍의 권능 | +5% | 낫터기가 쓰는 전투속도 보수값 |
| 수호 격앙 | +10% | 스킬 레벨을 몰라 lv10 기본 근처 |
| 검성 노련한 반격 | +9% | 본인 버프는 빼지 않음 |
| 치유 대지의 은총 | +6% | 게임 표기는 은총 (커뮤니티의 대지의 축복) |

같은 종류는 한 번만 더하고, `actorId == 본인`인 자버프는 nDPS에 남깁니다. 보호의 빛·불패의 진언도 자버프라 빼지 않습니다. 숫자 옆에는 `n/초`로 표시되니 실딜과 구분됩니다.

## 빌드하기

Windows에서 MSI를 만듭니다. 이 Cloud Agent 환경(Linux)에서는 Npcap/JavaFX win 의존성 때문에 패키징할 수 없습니다.

```bash
git clone https://github.com/wildcatXD/Aion2-Dps-Meter.git
cd Aion2-Dps-Meter
./gradlew packageDistributionForCurrentOS
```

산출물은 `bit-dps-meter-x.x.x.msi` 입니다.

## 사용법

1. npcap (https://npcap.com/#download) 를 설치합니다. (Install Npcap in WinPcap API-compatible Mode 필수 체크)

2. [Releases](https://github.com/wildcatXD/Aion2-Dps-Meter/releases)에서 `bit-dps-meter-x.x.x.msi`를 받아 설치합니다. 공식 AION2Meter4J MSI를 받으면 레기온 커스텀이 덮입니다.

3. **아이온이 켜져있는 상태라면 먼저 캐릭터 선택창으로 이동합니다**.

4. 프로그램이 설치된 위치 (기본 설치 경로 `C:\Program Files\bit-dps-meter`) 또는 시작 창의 바로가기에 `bit-dps-meter.exe`를 **반드시 관리자 권한으로 실행합니다.**

![image](./readme-asset/firstUI_new.png)

5. 위의 UI가 출력된다면 성공적으로 실행되었습니다.

6. 만약 에러가 발생하며 실행되지 않는다면, 관리자 권한으로 실행 되었는지 확인합니다.

설정 파일 경로는 업스트림과 같습니다. `%APPDATA%\Aion2DpsMeter\settings.properties`

## FAQ

- 업데이트를 눌렀는데 계속 똑같은 버전으로 나와요
  - 관리자 권한으로 실행하세요. 업데이트는 이 저장소 Releases만 봅니다.

- 업데이트는 완전 자동(무인) 설치인가요?
  - 반자동입니다. `업데이트` 버튼을 누르면 새 MSI를 내려받고, 다운로드가 끝나면 설치 마법사가 자동으로 열리며 미터기 자신은 종료됩니다. 파일을 직접 찾아 실행할 필요는 없지만, 설치 마법사의 다음/설치 버튼은 직접 눌러야 합니다 (조용한 무인 설치는 쓰지 않습니다).

- 미터기가 처음 실행때 잠깐 보였다 이후 보이지 않아요.
  - 미터기를 종료하고 win+r을 누른 뒤, `%appdata%\Aion2DpsMeter` 를 입력합니다. 해당 폴더에 settings.properties를 열어 windowX와 windowY, uiX, uiY 4개의 값을 0으로 변경한 다음 재실행합니다.

- 미터기에 표시되는 퍼센트는 보스의 체력을 기준으로 계산되나요?
  - 아닙니다. 보스의 전체 체력이 아닌, 파티원들이 가한 총 데미지 합계를 기준으로 퍼센트를 계산합니다.

- DPS 창에 5명 - 6명 등 파티에 없는 사람의 내역이 나와요.
  - 유저의 아이디 정보를 가지고 오지 못하거나, 소환물(마도성의 혹한의 바람 등 포함)이 너무 멀리서 소환되어 전투가 시작된 경우 소환물의 소환 정보를 가져오지 못해 발생하는 현상입니다.
  - 던전을 입장한 이후 수동 리셋을 하면 아이디 정보가 사라지기 때문에 문제가 있는 것이 아니라면, 수동 리셋 버튼을 누르지 않는 것을 추천드립니다.

- 치유성 등의 힐 스킬이 DPS에 포함되는거 같아요.
  - 힐량이 딜량안에 들어가는건 아니며, 보스치는 순간의 시간부터 집계가 시작됩니다. 정확하게는 보스를 친 딜량이 파티원을 회복시킨 수치보다 높으면 해당하는 몬스터의 DPS가 UI에 표기되기 시작합니다. 힐이 딜량에 집계되지는 않습니다.

- UI는 보이는데 본인 또는 다른사람의 데미지가 하나도 출력되지 않아요.
  - npcap이 제대로 설치되었는지 확인해보세요
  - 미터기를 완전히 종료하고, 캐릭터 선택창에서 실행된것을 확인하고 월드에 접속해보세요
  - 게임 패치 직후라면 옵코드가 깨진 것일 수 있습니다. [MAINTAINING.md](MAINTAINING.md)를 봅니다.

- 전투 상세보기에서 타격 횟수가 내가 스킬을 사용한 횟수보다 많이 나와요
  - 타격 횟수는 말 그대로 타격 횟수입니다. 만약 한번 스킬을 시전했을 경우 3번을 타격하는 스킬이라면, 스킬을 한번 시전했더라도 명중횟수는 3회가 됩니다

- 스킬명이 이상한 숫자로 나와요
  - 스킬으로 보이는 데이터의 스킬명이 숫자로 나온다면 `src/main/resources/json/skills.json`이 오래된 것입니다.

## 다음 업데이트 계획

타 미터기 대비 부족한 기능 요청을 검토 중입니다. 확정된 일정은 아니고, 패킷 리버스엔지니어링이 더 필요한 항목은 실제 전투 캡처로 검증하며 진행합니다.

- **본인 계정 탐지** — 이미 구현되어 있습니다 (1.8.10에서 extraFlag 패킷도 파싱). 본인 닉네임 패킷(`0x33 0x36`)을 받으면 `isExecutor`로 표시하고, 미터기 행에서 앰버(금색) 바로 본인을 구분합니다. 아래 두 기능의 기반이 됩니다. 그래도 숫자로만 보이면 `%APPDATA%\Aion2DpsMeter\app.log`의 `본인 닉네임` 로그를 확인합니다.
- **다른 모니터로 창 이동** — 지금은 오버레이 Stage/Scene을 `Screen.getPrimary().bounds`에만 맞춰서, 주 모니터 밖에는 창 자체가 없습니다. 듀얼/멀티 모니터에서는 `Screen.getScreens()`의 전체 영역(유니온)으로 투명 창을 키우거나, 모니터별로 위치를 기억하게 해야 게임 화면이 아닌 쪽으로 미터기를 넘길 수 있습니다.
- **오드에너지 등 리소스 게이지 표시** — 현재 패킷 파서는 보스 체력만 추적하고, 플레이어 본인의 오드에너지 같은 리소스를 읽는 옵코드가 아직 없습니다. 새로 리버스엔지니어링해야 하는 작업이라, 게임 내에서 오드에너지가 변할 때의 패킷 캡처가 필요합니다.
- **보스 스폰 알림** — 몹 소환/보스 판정 패킷은 이미 잡고 있어 스폰 시점 자체는 감지할 수 있지만, 타이머·알림 UI(토스트 등)는 아직 없습니다. 길드 웹의 아그로·공지 알림처럼 오버레이 헤더 종 아이콘으로 재사용하거나, 패킷 기반으로 직접 만드는 두 방향을 검토 중입니다.
