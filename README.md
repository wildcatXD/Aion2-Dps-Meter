# 빛 레기온 미터기

아이온2 전투분석을 위한 **빛 레기온 전용** 미터기입니다. 업스트림 [AION2Meter4J](https://github.com/TK-open-public/Aion2-Dps-Meter) (MIT, Copyright 2026 TK-open-public)를 포크했습니다.

[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

- Spoqa Han Sans Neo, Freesentation, Pretendard (OFL 1.1)
- NEXON Lv2 Gothic, Tmoney Round Wind (Custom License)

업스트림 공개 프로젝트는 2026-06-19 기준으로 종료되었습니다. 이 포크는 빛 레기온 내부용으로 파서·배포 채널을 유지합니다. 운영측 요청, 패킷 암호화, 공식 사용중단이 있으면 여기서도 멈춥니다.

길드 웹의 공지·일정 참여·아그로·필드보스 시간은 오버레이 헤더 종 아이콘으로 동기화합니다. 웹 `/meter-link`에서 코드를 만들고 미터기 설정에 넣으면 됩니다. 전투기록은 연동된 뒤 히스토리에서 웹으로 올릴 수 있습니다 (1.9.2+). 유지 절차는 [MAINTAINING.md](MAINTAINING.md)를 봅니다.

## 지금 되는 것 / 아직 안 되는 것

**지금 됩니다**

- Windows 오버레이 DPS (Npcap, 관리자 실행, 캐릭터 선택창에서 시작)
- 파티 기여도 / 보스 체력 기여도, 보스 HP 바, 스킬·버프 상세
- 전투 기록 20개 (RAM), 파티 신청 패널, 컴팩트/클릭 통과/자동 숨김/단축키
- 빛 레기온 테마 (네이비 `#0b0d17` + 앰버 `#fbbf24`). 업스트림 초록/금색 기본값은 한 번 레기온 테마로 바꿉니다. 직접 고친 색은 유지합니다.
- **실험적 nDPS**: 설정 → 딜 지표에서 `개인 nDPS · 실험`을 고르면 파티 시너지를 근사 제거한 값을 바·숫자에 씁니다. **실딜 rDPS는 nDPS가 아닙니다.** 상세 패널에는 두 숫자를 같이 보여 줍니다.
- **길드 웹 연동 (알림·참여)**: 웹 `/meter-link` 코드를 미터기 설정에 넣으면, 헤더 종 아이콘으로 안 읽은 공지·내 일정·열린 일정 참가·아그로 참가/불참·곧 뜨는 필드보스를 받을 수 있습니다. 아그로·우선 보스 임박은 미터 위 토스트로도 뜹니다.
- 오버레이를 **연결된 모니터 전체**에서 옮길 수 있습니다 (1.9.0+). 주 모니터보다 큰 화면은 1.8.5부터, 다른 모니터로 넘기는 것은 1.9.0부터입니다. 빈 투명 영역이 클릭을 먹으면 패스스루(기본 Ctrl+T)를 켭니다.
- **추적 오버레이 (기본 꺼짐, 1.9.3+)**: 고른 스킬만 **별도 창**. 오드·열쇠·본인 버프는 1.9.10부터 미터기 창에 붙습니다. 캐릭터 아래 아이콘은 낫터기입니다.
- 켜 둔 동안 30분마다 새 버전을 다시 확인합니다 (1.8.7+). 작업표시줄 숨겨진 아이콘(트레이)에 미터기가 등록됩니다 (1.8.8+).
- 업데이트 다운로드가 끝나면 설치 마법사 없이 종료 → 무인 설치 → 미터기 자동 재실행까지 진행합니다 (1.9.4+). 1.9.3까지는 헬퍼 cmd가 보이거나 설치가 실패할 수 있습니다.
- **전투기록 웹 업로드 (1.9.2+)**: 길드 웹 연동 후 히스토리에서 스냅샷만 올립니다. 낫터기 수집 API는 쓰지 않습니다.
- 본인·파티 닉네임 패킷의 extraFlag를 건너뛰어, 딜이 숫자 ID로만 보이던 문제를 고쳤습니다 (1.8.10+). 스폰을 못 받은 허수아비는 1.9.10부터 전투 중 카탈로그 코드·이름 보조탐지로 `훈련용 허수아비`를 붙입니다. 그래도 없으면 `미확인 대상`입니다. 캐릭터 선택 전에 미터기를 못 켠 경우에는 전투 uid로 이름을 보조 탐지하고, 솔로면 `나`로 표시합니다 (1.8.11+).
- 멀티히트 횟수를 합딜에 반영합니다 (1.9.5+). 허수아비·스폰 전 NPC 체력 패킷도 저장합니다.

**아직 없습니다**

- 권성 직업 카탈로그
- 권성 직업 아이콘·스킬 카탈로그 (1.7.5 json에 19xxxxxx 없음)
- 7월 이후 던전 보스 한글 이름 전부
- 낫터기와 같은 정밀 nDPS (개인 PvE 증폭·스킬 레벨 없음)
- 보스 스폰 **패킷** 알림, 슈고페스타 열쇠 **실제 갯수**(전용 옵코드 캡처 필요). 오드에너지는 1.9.9부터 로그인 스냅샷으로 표시합니다.

**주의**

- 게임 패치 후 옵코드가 깨지면 딜이 안 뜹니다. [MAINTAINING.md](MAINTAINING.md)
- 이 Cloud Agent(Linux)에서는 MSI/Npcap을 돌릴 수 없습니다. Windows에서 다시 빌드하세요.

## nDPS (실험)

아이온2에서 말하는 nDPS는 전투시간을 정규화한 값이 아니라, **남이 걸어 준 파티 시너지를 뺀 개인 딜**입니다. 낫터기 공식은 타격마다 `기존 PvE 증폭 + 버프 증폭`을 합친 뒤 차이만 시너지로 뺍니다. 이 미터기는 장비 스탯 시트를 못 읽어서 개인 증폭을 0으로 두고, 알려진 파티 버프만 보수적으로 뺍니다.

| 버프 | 시너지 근사 | 비고 |
| --- | --- | --- |
| 호법 질풍의 권능 | +5% | 낫터기가 쓰는 전투속도 보수값 |
| 수호 격앙 | +10% | 스킬 레벨을 몰라 lv10 기본 근처 |
| 검성 노련한 반격 | +9% | 본인 버프는 빼지 않음 |
| 치유 대지의 은총 | +6% | 게임 표기는 은총 (커뮤니티의 대지의 축복) |

같은 종류는 한 번만 더하고, `actorId == 본인`인 자버프는 nDPS에 남깁니다. 보호의 빛·불패의 진언도 자버프라 빼지 않습니다. 숫자 옆에는 `n/초`로 표시되니 실딜과 구분됩니다.

## 빌드하기

Windows에서 MSI를 만듭니다. 이 Cloud Agent 환경(Linux)에서는 Npcap/JavaFX win 의존성 때문에 패키징할 수 없습니다.

```bash
git clone https://github.com/wildcatXD/Aion2-Dps-Meter.git
cd Aion2-Dps-Meter
./gradlew packageDistributionForCurrentOS
```

산출물은 `bit-dps-meter-x.x.x.msi` 입니다.

## 사용법

1. npcap (https://npcap.com/#download) 를 설치합니다. (Install Npcap in WinPcap API-compatible Mode 필수 체크)

2. [Releases](https://github.com/wildcatXD/Aion2-Dps-Meter/releases)에서 `bit-dps-meter-x.x.x.msi`를 받아 설치합니다. 공식 AION2Meter4J MSI를 받으면 레기온 커스텀이 덮입니다.

3. **아이온이 켜져있는 상태라면 먼저 캐릭터 선택창으로 이동합니다**.

4. 프로그램이 설치된 위치 (기본 설치 경로 `C:\Program Files\bit-dps-meter`) 또는 시작 창의 바로가기에 `bit-dps-meter.exe`를 **반드시 관리자 권한으로 실행합니다.**

![image](./readme-asset/firstUI_new.png)

5. 위의 UI가 출력된다면 성공적으로 실행되었습니다.

6. 만약 에러가 발생하며 실행되지 않는다면, 관리자 권한으로 실행 되었는지 확인합니다.

설정 파일 경로는 업스트림과 같습니다. `%APPDATA%\Aion2DpsMeter\settings.properties`

## FAQ

- 업데이트를 눌렀는데 계속 똑같은 버전으로 나와요
  - 관리자 권한으로 실행하세요. 업데이트는 이 저장소 Releases만 봅니다.

- 업데이트는 완전 자동(무인) 설치인가요?
  - 1.9.4부터는 검은 cmd 없이 종료 → 무인 설치 → 재실행입니다. 1.9.1~1.9.3 헬퍼는 cmd 창이 남거나, 한글 경로에서 설치가 실패해 예전 버전으로 다시 뜨는 경우가 있습니다. 그때는 Releases의 MSI를 직접 실행하세요. 1.9.0 이하에서 올리면 Setup 창이 한 번 뜰 수 있습니다.

- 미터기가 디스코드·브라우저 위를 계속 덮어요
  - 설정 → 일반의 **아이온 창 위에만**이 꺼져 있으면 모든 창 위에 고정됩니다. 기본은 켜 두어 아이온이 앞에 있을 때만 게임 위로 올립니다. 아이온을 내리면 미터기도 같이 뒤로 갑니다. 완전히 숨기려면 **자동 숨김**을 켭니다.

- 미터기가 처음 실행때 잠깐 보였다 이후 보이지 않아요.
  - 미터기를 종료하고 win+r을 누른 뒤, `%appdata%\Aion2DpsMeter` 를 입력합니다. 해당 폴더에 settings.properties를 열어 windowX와 windowY, uiX, uiY 4개의 값을 0으로 변경한 다음 재실행합니다.

- 미터기에 표시되는 퍼센트는 보스의 체력을 기준으로 계산되나요?
  - 기본값은 파티가 가한 총딜 대비 기여입니다. 설정에서 보스 체력 대비로 바꿀 수 있습니다. 허수아비는 1.9.5부터 체력 패킷을 저장합니다. 스폰을 못 받은 대상은 1.9.10에서 이름을 보조탐지하고, 그때까지는 `미확인 대상`이어도 체력은 올라갈 수 있습니다.

- 낫터기와 같은 자리에서 쳤는데 딜이 훨씬 낮아요
  - 1.9.4까지는 멀티히트 횟수를 세고도 한 대분만 합산했습니다. 1.9.5에서 횟수를 곱합니다. 그래도 이름·닉네임이 비면 캐릭터 선택 전에 관리자로 켜세요. 낫터기의 전투 보조 UI(쿨·인벤)는 패킷 캡처가 오기 전에는 따라가지 않습니다.

- DPS 창에 5명 - 6명 등 파티에 없는 사람의 내역이 나와요.
  - 유저의 아이디 정보를 가지고 오지 못하거나, 소환물(마도성의 혹한의 바람 등 포함)이 너무 멀리서 소환되어 전투가 시작된 경우 소환물의 소환 정보를 가져오지 못해 발생하는 현상입니다.
  - 던전을 입장한 이후 수동 리셋을 하면 아이디 정보가 사라지기 때문에 문제가 있는 것이 아니라면, 수동 리셋 버튼을 누르지 않는 것을 추천드립니다.

- 치유성 등의 힐 스킬이 DPS에 포함되는거 같아요.
  - 힐량이 딜량안에 들어가는건 아니며, 보스치는 순간의 시간부터 집계가 시작됩니다. 정확하게는 보스를 친 딜량이 파티원을 회복시킨 수치보다 높으면 해당하는 몬스터의 DPS가 UI에 표기되기 시작합니다. 힐이 딜량에 집계되지는 않습니다.

- UI는 보이는데 본인 또는 다른사람의 데미지가 하나도 출력되지 않아요.
  - npcap이 제대로 설치되었는지 확인해보세요
  - 미터기를 완전히 종료하고, 캐릭터 선택창에서 실행된것을 확인하고 월드에 접속해보세요
  - 게임 패치 직후라면 옵코드가 깨진 것일 수 있습니다. [MAINTAINING.md](MAINTAINING.md)를 봅니다.

- 전투 상세보기에서 타격 횟수가 내가 스킬을 사용한 횟수보다 많이 나와요
  - 타격 횟수는 말 그대로 타격 횟수입니다. 만약 한번 스킬을 시전했을 경우 3번을 타격하는 스킬이라면, 스킬을 한번 시전했더라도 명중횟수는 3회가 됩니다

- 스킬명이 이상한 숫자로 나와요
  - 스킬으로 보이는 데이터의 스킬명이 숫자로 나온다면 `src/main/resources/json/skills.json`이 오래된 것입니다.

## 다음 업데이트 계획

타 미터기 대비 부족한 기능 요청을 검토 중입니다. 확정된 일정은 아니고, 패킷 리버스엔지니어링이 더 필요한 항목은 실제 전투 캡처로 검증하며 진행합니다.

- **본인 계정 탐지** — 이미 구현되어 있습니다 (1.8.10에서 extraFlag 패킷도 파싱). 본인 닉네임 패킷(`0x33 0x36`)을 받으면 `isExecutor`로 표시하고, 미터기 행에서 앰버(금색) 바로 본인을 구분합니다. 그래도 숫자로만 보이면 `%APPDATA%\Aion2DpsMeter\app.log`의 `본인 닉네임` 로그를 확인합니다.
- **다른 모니터로 창 이동** — 1.9.0에서 `Screen.getScreens()` 유니온으로 넣었습니다.
- **웹 필드보스·아그로 알람** — 1.9.0. 길드 웹 인박스의 출현 시간·아그로 라운드를 종 아이콘과 토스트로 보여 줍니다. 게임 스폰 패킷으로 뜨는 알림은 아닙니다.
- **추적 오버레이** — 1.9.3부터 미터기와 별도 창(기본 꺼짐). 고른 스킬만 그쪽에 둡니다. 오드·열쇠·본인 버프 남은 시간은 1.9.10부터 미터기 창에 고정합니다. 캐릭터 아래 버프 HUD는 낫터기입니다. 재사용 대기 전용 패킷은 아직 없습니다.
- **멀티히트 합딜** — 1.9.5. 파서가 세 둔 타수(`loop`)를 DPS 합산에 넣습니다.
- **허수아비 체력** — 1.9.5. 보스뿐 아니라 허수아비·스폰 전 인스턴스에도 RemainHp를 저장합니다. 고정 NPC 스폰(`0x40 0x36`, 1.9.9+)이 있으면 `훈련용 허수아비`처럼 이름이 붙습니다. 미터기를 늦게 켜 스폰을 놓친 경우에는 1.9.10부터 전투 중 카탈로그 코드·UTF-8 이름을 보조탐지합니다. 허수아비 전투도 1.9.10부터 전투기록에 남습니다.
- **아이온 창 위에만** — 1.9.10. 기본으로 아이온 창 바로 위에만 두고, 다른 앱을 앞에 두면 미터기는 뒤로 갑니다. 설정에서 끄면 예전처럼 모든 창 위에 고정합니다.
- **오드에너지** — 1.9.9. 월드 진입 스냅샷(`0x0B 0x61`)과 변동(`0x0C 0x61`)으로 미터기 창에 총량을 표시합니다. 슈고페스타 열쇠는 아직 전용 필드가 없어 `—`입니다. 별도 추적 창으로 분리하지 않습니다.
- **전투기록 웹 업로드** — 1.9.2. 연동된 기기 토큰으로 `bit-legion-encounter-v1` 스냅샷만 `POST /api/meter/encounters`. 낫터기 ingest는 쓰지 않습니다.

### 캡처가 필요한 것 (파서 금지)

숫자는 추측하지 않습니다. 아래가 `%APPDATA%\Aion2DpsMeter\app.log`와 함께 오면 그때 옵코드를 붙입니다.

1. **슈고페스타 열쇠** — 획득, 사용, 인벤에서 갯수가 보일 때. 오드에너지 스냅샷(`0x0B 0x61`)의 다른 field id일 수 있습니다.
2. **스킬 재사용 대기** — 버프 남은 시간과는 다릅니다. 스킬을 쓴 직후 쿨이 돌기 시작하는 구간의 패킷. 지속 버프가 없는 딜 스킬의 “쿨 n초”는 이 캡처 없이 HUD에 넣지 않습니다.
